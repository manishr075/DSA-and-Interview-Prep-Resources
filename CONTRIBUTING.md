# Contributing

Thanks for helping improve this DSA and interview prep resource collection.

## What to contribute

- New high-quality DSA/interview preparation resources
- Link fixes for outdated or broken resources
- Clearer descriptions for existing resources

## Contribution guidelines

1. Keep entries educational, relevant, and publicly accessible.
2. Preserve original attribution/title of the resource.
3. Add a short, neutral description.
4. Verify links before opening a pull request.
5. Keep changes focused (avoid unrelated formatting-only churn).

## Resource entry format

Add resources in the README table using this format:

| Resource | Description | Link |
| :--- | :--- | :---: |
| **Resource Name** | One-line summary of why it is useful. | [Open](https://your-resource-url) |

## Pull request checklist

- [ ] I verified all links I added/changed.
- [ ] I kept resource attribution intact.
- [ ] I added concise, factual descriptions.
- [ ] I ran local markdown/link checks if possible.
