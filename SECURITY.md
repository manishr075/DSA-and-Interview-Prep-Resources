# Security Policy

## Reporting unsafe links or malicious content

If you find a resource link that appears malicious, misleading, or unsafe:

1. Open a GitHub issue with the label `security` and include the affected entry.
2. Avoid posting sensitive information in public issue comments.
3. If you need private coordination, mention that in the issue and maintainers can follow up.

## Scope

This repository primarily contains educational links and documentation. Security efforts focus on:

- removing or replacing unsafe links,
- keeping maintenance workflows updated, and
- reviewing contribution quality.
